INTRODUCTION

About
This
Project

This is an experimental version of BCDD, a (poorly-developed) database & navigator tool which aims to record information about drugs encountered in our studies and careers.

This is only a personal project and is for personal use only (Though I'm not sure if it'll be of any use realistically). The reason why this may seem excessively decorated is thanks to boredom and not ambition.

Please also be aware of the fact that I am NOT a good programmer/developer at all. As evidenced by the incredibly messy code (As I tried to limit the amount of vibe-coding).

Use on desktop/laptop is recommended.

Any contribution is welcomed.
